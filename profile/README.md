# MFL Decision Engine · CIAT-MFL

**An open, use-case-driven decision engine for multifunctional landscapes.**
CGIAR Multifunctional Landscapes Science Program · Alliance of Bioversity International and CIAT

The MFL Decision Engine turns fragmented landscape data, scientific models, rules and stakeholder preferences into
**explainable, actionable recommendations** (Decision Cards) for farmers, extension agents, landscape planners,
investors and policy makers — one decision domain at a time.

| Repository | What it is |
|---|---|
| [`mfl-decision-engine`](https://github.com/CIAT-MFL/mfl-decision-engine) | The engine: contracts (JSON schemas), registries, decision intelligence, Decision Card service, API and web app |

**How we build:** one complete, thin decision loop per use case; contracts before code; registries as the system of
record; the engine computes and the language model only explains. See the implementation roadmap in the engine
repository (`docs/`).

**Use Case 1:** Agroecology-Based Practice Recommendation (MFL-APR) — evidence-based CSA practice advice for any
location in Ethiopia.
